# Forensic-Analysis-of-Chopping-Hacking-Sharp-Force-Trauma-Dissertation
This repository contains the raw data, processed data, and R code associated with K. McGehee's doctoral dissertation, Forensic Analysis of Sharp Force Trauma: Macroscopic and Microscopic Examination of Chopping/Hacking Cut Marks on Bone and Taphonomic Considerations, completed at the University of Central Florida.
